# Document Fraud & Anomaly Screening System

An interpretable document anomaly screening system using classical Machine Learning, NLP, OCR and basic image processing.

## Project Goal

The system analyzes document images/PDFs using visual, textual and structured features to identify suspicious or anomalous patterns.

## Important Limitation

This project is an educational screening system. It does not legally prove that a document is fraudulent. It identifies patterns that may warrant further review.
